# StockPilot

本地研究证据与模拟交易项目。本次工程版本为 0.5.1；未发布，也不宣称有外部用户、投资收益或实时数据源验收结果。

核心用法、完整限制和配置见 [英文 README](README.md)。

## 安全验证

使用 Python 3.12，在项目目录运行：

```powershell
python -m venv .venv-offline
.\.venv-offline\Scripts\python.exe -m pip install -r scripts/requirements-offline-lock.txt
.\.venv-offline\Scripts\python.exe scripts/test_offline.py
```

测试自动在 work/offline-tests 下创建独立状态目录，使用合成数据并拒绝 Python 网络连接。不要把依赖已有研究报告的第四/第五阶段脚本当作普通单元测试直接运行。

`STOCKPILOT_HOME` 可在导入前设置为绝对路径，以隔离数据、审计、日志和报告。不设置则保留原目录行为。不会自动读取 .env。调度和新时间戳统一使用上海市场时区；缺少交易日历时仅按工作日判断，不能准确识别节假日。

## 已修复

- 午间误判收盘、盘前窗口说明矛盾和外地时区误判。
- 模拟委托接受负数、非整数数量或无效价格；指定日期缺行情却回退到别日数据。
- 同一模拟委托并发重复处理；历史市场日期与处理时刻混淆影响 T+1。
- JSON 写入失败破坏旧文件；交接包校验读取越界文件名。
- 新目录导出依赖旧报告；固定模型署名、固定全市场数量等无证据表述。

模拟数据库通过 `simulation.init_db()` 增加可空 trade_date 列，保留旧记录；本轮不会对用户原数据库执行迁移。历史旧记录没有独立市场日期时仍回退到原时间戳，不猜测或改写历史。

## 边界

仅模拟，不连接券商、不使用真实资金；主回测仍不是完整历史回测。原手工账本功能保留，不能据此扩大交易权限。本次不修改税费规则，也不声称重新核实了当前费率。原全量依赖清单保留；现有环境与清单存在版本差异，最小离线测试不证明全部行情采集功能可用。
